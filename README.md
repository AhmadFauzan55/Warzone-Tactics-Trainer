Aurora respectfully observes the principle of **"help, don't hijack."** It does not inject foreign code into game memory, modify match files, or alter network packets. Instead, it reads publicly accessible game telemetry (screen state, UI elements, and system metrics) to derive insights.

## Troubleshooting: Common Crossroads 🧭

**"Aurora doesn't detect my game window."** – Ensure Warzone2100 is running in windowed mode (hotkey: Alt+Enter). Also, some overlay software (e.g., hardware monitoring tools) may intercept the detection heuristic. Temporarily disable those and retry.

**"Overlay is blurry on my 4K screen."** – Navigate to Settings → Display → and toggle "Pixel Density Compensation". This re-rasterizes all vectors at native resolution.

**"Calculations seem delayed by ~2 seconds."** – This is intentional. Aurora uses a **sliding window smoothing algorithm** to avoid reacting to micro-spikes in game telemetry. You can reduce this interval in advanced settings, but we recommend keeping it to avoid information noise.
